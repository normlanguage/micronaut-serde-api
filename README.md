# Micronaut Serde API

[English](README.md) | [简体中文](README.zh-CN.md)

`micronaut.serde.api@3` binds the commonly used `@Serdeable`, `@SerdeImport`, and ObjectMapper APIs from Micronaut Serialization 3.1.1. Compile-time and Jackson runtime examples are in [micronaut-serde-jackson/sample/sample/serde](https://github.com/normlanguage/micronaut-serde-jackson/tree/main/sample/sample/serde).

[Sample ownership](samples/README.md).

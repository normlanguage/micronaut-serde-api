# Micronaut Serde API

[English](README.md) | [简体中文](README.zh-CN.md)

`micronaut.serde.api@3` 绑定 Micronaut Serialization 3.1.1 的 `@Serdeable`、`@SerdeImport` 和 ObjectMapper 常用 API。编译期与 Jackson 运行时示例位于 [micronaut-serde-jackson/sample/sample/serde](https://github.com/normlanguage/micronaut-serde-jackson/tree/main/sample/sample/serde)。

[示例归属](samples/README.zh-CN.md)。

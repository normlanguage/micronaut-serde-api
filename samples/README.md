# micronaut-serde-api sample ownership

[English](README.md) | [简体中文](README.zh-CN.md)

This module supplies the @Serdeable annotation and mapper API. The runnable scenario is owned by [micronaut-serde-jackson](https://github.com/normlanguage/micronaut-serde-jackson/tree/main/samples) in its `samples/` directory; use that example to observe the behavior through the public API.

The module identity and pinned dependencies are defined in [module.norm](../micronaut/serde/api/module.norm).

# micronaut-serde-api 示例归属

[English](README.md) | [简体中文](README.zh-CN.md)

本模块提供 @Serdeable 注解与映射器 API。可运行场景由 [micronaut-serde-jackson](https://github.com/normlanguage/micronaut-serde-jackson/tree/main/samples) 仓库的 `samples/` 目录负责；请通过该示例观察公开 API 的实际行为。

模块身份与固定依赖见 [module.norm](../micronaut/serde/api/module.norm)。
